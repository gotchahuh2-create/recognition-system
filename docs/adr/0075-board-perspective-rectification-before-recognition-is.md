# ADR-0075: Board perspective rectification before recognition is opt-in (`--rectify`)

- Date: 2026-11-05
- Status: Accepted
- Source: DECISIONS.md row 75 (migrated)

## Decision

Board perspective rectification before recognition is opt-in (`--rectify`)

## Context and reason

The board outline from a preview-grade detector could crop edge text; the pipeline already deskews and fits the layout homography; the guidance keeps tilt < ~5° anyway
