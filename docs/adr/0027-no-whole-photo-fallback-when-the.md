# ADR-0027: No whole-photo fallback when the MCU-card ROI abstains (option `--roi-fallback`)

- Date: 2026-11-03
- Status: Accepted
- Source: DECISIONS.md row 27 (migrated)

## Decision

No whole-photo fallback when the MCU-card ROI abstains (option `--roi-fallback`)

## Context and reason

If the card is where the layout says, the rest of the photo only adds wrong candidates and time
