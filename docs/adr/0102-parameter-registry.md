# ADR-0102: One parameter registry, generated from the code, with binding detection

- Date: 2026-11-09
- Status: Accepted

## Decision

`config/params.yaml` lists every UPPER_CASE numeric constant in `vision/` (105 at v1), generated by
`python -m phoenix params extract`; `params check` fails on drift. Overrides are applied per run and
restored afterwards. Constants captured as default arguments or imported by value are marked `bound`:
an override cannot reach them, so `apply` refuses them instead of silently doing nothing. Six bound
decision thresholds (board/MCU accept + margin, card accept, card-locate accept) are reachable through
the built pipeline instance (`via:` in the registry).

## Consequences

Tuning no longer needs code edits. Making another bound constant tunable is a code change (needs an ADR).
