# ADR-0079: UI restyled after NECTO Studio 7 (flat near-black panels, amber outlined / filled buttons,

- Date: 2026-11-05
- Status: Accepted
- Source: DECISIONS.md row 79 (migrated)

## Decision

UI restyled after NECTO Studio 7 (flat near-black panels, amber outlined / filled buttons, setup card with icon rows + amber action bar, status bar with *Active setup*); phone page in an iOS-camera idiom (step bar, one instruction, progress ring on the shutter, bottom sheets between steps)

## Context and reason

Asked for NECTO look on the PC and a polished phone flow

## Evidence

headless Chromium screenshots with a fake camera
