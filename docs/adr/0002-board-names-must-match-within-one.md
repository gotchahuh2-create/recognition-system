# ADR-0002: Board names must match within one text line (or two stacked lines)

- Date: 2026-11-03
- Status: Accepted
- Source: DECISIONS.md row 2 (migrated)

## Decision

Board names must match within one text line (or two stacked lines)

## Context and reason

Whole-board word matching let chip text "STM32" and "mikroBUS 2" vote for wrong boards

## Evidence

synthetic run, fusion_arm / clicker4 scenes
