# ADR-0056: Multi-scale variants: un-smoothed projection kept only inside the zone of the smoothed tex

- Date: 2026-11-05
- Status: Accepted
- Source: DECISIONS.md row 56 (migrated)

## Decision

Multi-scale variants: un-smoothed projection kept only inside the zone of the smoothed text

## Context and reason

Stroke-scale smoothing fills letter detail (M→H/N, ERET6) — on easy chips faint was worse than classic until this

## Evidence

easy chips: faint 1/2 → 2/2
