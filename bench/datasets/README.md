## Labelling the captures (needed for real-photo accuracy)

1. `python -m phoenix datasets template` writes `photos/captures/labels.TEMPLATE.csv`, pre-filled with
   today's predictions.
2. Copy it to `photos/captures/labels.csv`, correct every value you know (board key, MCU part, card key,
   layout group from `data/mcu_cards.json`), leave unknown cells empty, set `verified` to `yes`.
3. `python -m phoenix datasets build` - the captures manifest now carries truth; benchmarks score it.

New real photos: save them from the app's Photos tab ("Save to dataset") or the Scan tab
(`photos/captures/`), label them the same way, rebuild the manifests.

Synthetic images depend on the OpenCV/Pillow fonts and versions; the SHA-256 in the manifest tells you
when a regenerated set differs from the one the reference report used (`Dataset.items(check_hash=True)`).
